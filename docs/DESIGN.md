# طراحی «رصدخانه»

هویت بصری صابی از اسطرلاب و هندسهٔ گره‌چینی ایرانی الهام گرفته است: شب نیلی، طلای زعفرانی و تأکید فیروزه‌ای؛ در تم روشن، پوست‌نوشت و جوهر لاجوردی.

| بخش | توضیح |
| --- | --- |
| فونت | Vazirmatn برای متن، Aref Ruqaa (OFL) برای عنوان‌ها |
| رنگ تأکید | فیروزه‌ای، زعفرانی، یاقوتی، لاجوردی، زمردی (`localStorage: sabi-accent`) |
| پالت فرمان | `Ctrl/⌘+K` یا `/`؛ سایت‌ها، دروازه‌ها، تم و رنگ، و در نشست: کپی لینک، QR، تمدید، عکس، پایان |
| سایت‌های اخیر | فقط در `localStorage` همین مرورگر (`sabi-recent`)، با دکمهٔ «پاک‌کردن» |
| دسترس‌پذیری | `prefers-reduced-motion` همهٔ انیمیشن‌ها را خاموش می‌کند؛ پالت `role=dialog/listbox` دارد |
| ساخت | `python3 app/design/build.py` قطعه‌های `app/design/parts` را به `ui.html` تزریق می‌کند (مسیرها را با محیط خود تنظیم کنید) |

شناسهٔ همهٔ عناصر قدیمی (`#target`، `#start`، `#workspace`، …) دست‌نخورده مانده تا منطق برنامه تغییری نکند.
